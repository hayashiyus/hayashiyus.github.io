# 日本語で推敲するための原稿

編集対象は `../research.ja.md` です。図注と代替テキストは `../assets/figures.ja.json` にあります。日本語版の本文・数式・図注・折り畳み・脚注を、現在の英語版と対応づけています。

## 推奨する進め方

1. 日本語版を読み、言いたいこと、説明の順序、語り口を `research.ja.md` で整える。
2. 数値・数式・専門用語・主張の強さを変えた箇所は、意図した変更かを確認する。特に「局所的」「未完了」「実測ではなく模式図」といった条件は、表現上の飾りではない。
3. 英語へ戻す際は、日本語だけを新規翻訳するのではなく、英語原文と日本語の変更前後を比較し、改稿の意図を英語原文へ反映する。
4. 最後に英語の自然さと技術的な意味の維持を別々に確認する。AIによる英文校正も、著者の意図が保たれているかの確認に代わるものではない。

## 対応を残すファイル

- `research.en.source.md`：翻訳時点の英語原文。変更しない。
- `research.en.before-revision.md`：日本語推敲を反映する直前の英語原稿。
- `research.ja.approved.md`：著者が確認した日本語推敲稿。英語への反映元として保存。
- `figures.en.before-revision.json`：英語の図注を推敲する前のマニフェスト。
- `english-revision-qa.json`：英語改稿後の数式・数値・図・参照の照合記録。
- `research.ja.initial.md`：日本語訳の初版。変更しない。
- `research.ja.before-polish.md`：今回の全面推敲前の原稿。変更前後を確認するために保存。
- `alignment.json`：原文・訳文のハッシュ、節対応、数式などの照合記録。
- `../research.ja.md`：ユーザーが推敲する本文。
- `../assets/figures.ja.json`：推敲する図注・代替テキスト。

数式、プログラム、図の参照記号、脚注のID、リンク先は原文と対応を保っています。図・動画に焼き込まれた英語は、承認済みの作品をそのまま使用しています。図注と表紙動画の注釈対訳を日本語で読めるようにしています。これは原文の翻訳であり、文献や実験の再監査ではありません。

## 表示を更新する

リポジトリのルートで実行します。

```sh
python3 blog/feature/build_ja.py --publish-local
```

日本語版は `http://localhost:8876/blog/weight-space-geometry/ja/` に出力されます。公開済みの外部サイトへのアップロードは行いません。

用語は原則として、activation＝活性化、steering＝ステアリング、metric＝計量、weight edit＝重み編集、reachable＝実現可能、pullback＝引き戻し、natural gradient＝自然勾配、と統一しています。prefixはモデルへ与える先行トークン列を指し、技術用語として英語表記を残しています。

## 確認済みの日本語稿から英語版へ

著者が日本語稿を確認し、英語への反映を指示した後、英語本文と全10図の図注・代替テキストを改稿しました。日本語の説明順と段落構成を反映し、語順や言い回しは自然な研究英語に整えています。確認済みの日本語本文・図注と、画像・動画のファイルは変更していません。

英語改稿前の原稿と確認済みの日本語稿の両方に対して、数式・数値・コード・図順・リンク・脚注の照合を行っています。意味の照合では、測定結果と原著報告、局所近似と有限変化、実証済みの結果と提案段階の手法を区別し、主張の強さと留保を確認しました。

```sh
python3 blog/feature/verify_english_revision.py
python3 blog/feature/build.py
python3 blog/feature/build_ja.py --publish-local
```

改稿した英語版のローカル確認先は `http://localhost:8876/blog/weight-space-geometry/en/` です。既存の節リンクは維持しています。英語の折り畳み内も本文・コードとして描画するようにしました。外部サイトへの公開操作は行っていません。
